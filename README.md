# Readora

Readora is a digital reading platform where authors can publish their books and readers can discover, read, and earn.

## Vision

To create a beautiful and secure reading community that connects authors and readers while rewarding reading.

## Core Features

- Author book publishing
- Online book reading
- Reader profiles
- Author profiles
- Reading progress
- Success Tree
- Reader rewards
- Subscriptions and payments
- Secure authentication
- Admin dashboard
- Mobile-friendly design
